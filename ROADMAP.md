## 🛠️ Technology Stack

### Core
- **Language**: Python 3.8+
- **Storage**: File-based with JSON indexing
- **Testing**: pytest, hypothesis
- **Documentation**: Sphinx

### Edge Deployment
- **Models**: Phi-2, CodeLlama-7B, Mistral-7B
- **Inference**: ONNX Runtime, llama.cpp
- **Packaging**: Docker, pip wheels
- **Platforms**: Linux, macOS, Windows, ARM

### Infrastructure
- **API**: FastAPI, GraphQL
- **Database**: SQLite for metadata
- **Cache**: Redis for hot tissues
- **CDN**: CloudFlare for distribution
