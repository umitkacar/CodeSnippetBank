## 🎯 Usage Examples

### Example 1: Using LLM Snippets
```python
from llm.gpt4_basic_integration import GPT4Client

client = GPT4Client()
response = client.complete("Explain quantum computing")
print(response.content)
```

### Example 2: Using Computer Vision
```python
from computer_vision.yolo_object_detection import YOLODetector

detector = YOLODetector()
result = detector.detect("image.jpg")
print(f"Found {len(result.detections)} objects")
```

### Example 3: Using NLP
```python
from nlp.named_entity_recognition import SpaCyNER

ner = SpaCyNER()
result = ner.extract("Apple Inc. is in California")
for entity in result.entities:
    print(f"{entity.text}: {entity.label}")
```

### Example 4: Using Generative AI
```python
from generative_ai.stable_diffusion_xl import SDXLGenerator

generator = SDXLGenerator()
config = GenerationConfig(
    prompt="A beautiful sunset over mountains",
    num_inference_steps=30
)
images = generator.generate(config)
```
